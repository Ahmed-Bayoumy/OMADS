generate_quad_model_points(hashtable, fc, x_parent=None)[source]#

Cheap search, meant to run first every iteration (at most two evaluations):

  • speculative search: right after a success (x_parent is the point the incumbent was generated from), repeat that successful step once more from the incumbent;

  • quadratic model search (see _quad_model_point).

Single-objective only. With constraints (constraints_type set), the constraints are modelled too and the frame center may be infeasible (see _constrained_quad_model_point); otherwise the incumbent must be feasible. Leaves the candidate set empty when there is nothing worth evaluating.

Parameters:

  • hashtable (Cache)

  • fc (CandidatePoint)

  • x_parent (List[float] | None)
